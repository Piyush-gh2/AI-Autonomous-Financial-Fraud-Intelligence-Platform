# 💳 AI Autonomous Financial Fraud Intelligence Platform

## 🚀 Overview

An AI-powered financial intelligence platform that detects fraud patterns, predicts suspicious activities, and generates explainable financial risk insights using predictive analytics, RAG, and multi-agent architecture.

---

## 💡 Features

- Fraud risk forecasting
- Transaction anomaly detection
- Explainable AI insights
- RAG-powered financial intelligence
- Multi-agent coordination
- Streamlit dashboard

---

pip install -r requirements.txt

## ▶️ Run Project

streamlit run app.py
